# Portraits folder

Use this folder to **organize image files manually**. Create a square portrait with a Karacter prompt, save it to your computer, and optionally keep a copy here. Then drag the image into **Character portrait** in the app.

Karacter converts imported images to square PNG for its browser storage. **It does not write images into this directory automatically.** You can download a renamed image from a character sheet.

See [Images and prompts](../docs/wiki/IMAGES_AND_PROMPTS.md).
