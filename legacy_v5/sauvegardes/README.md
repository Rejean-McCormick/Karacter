# Backups folder

Use this folder to **organize exported Karacter backup files manually**.

For a full backup, choose **Backup ZIP** in the app. The downloaded ZIP contains character TXT sheets, image prompts and a JSON backup including the portraits. Move the file here if desired; to restore, select **Import** inside Karacter and open that ZIP.

Other formats: `.json` is a complete backup including images; `.txt` is an individual image-free character sheet; a ZIP of TXT sheets does not include images.

**Note:** Moving a file into this folder does not trigger an automatic import.

See [Backups and imports](../docs/wiki/BACKUPS_AND_IMPORTS.md).
