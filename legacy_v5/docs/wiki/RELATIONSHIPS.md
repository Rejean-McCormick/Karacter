# Character relationships

Open **Studio** mode and choose a character. Under **Character relationships**, select another existing character, choose a relationship type (ally, rival, mentor, protected person, family or other), and add notes.

Relationships are directional: a character can see someone as a mentor without a reciprocal relationship being created. If you want both viewpoints, add a link from the other character as well. Deleted characters are displayed as missing references rather than silently reassigned.

Links are saved in character TXT sheets as structured JSON and in full collection backups. Images are not stored in TXT files.
