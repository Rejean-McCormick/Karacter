# Three image modes

Karacter generates **text prompts** for image creation; it does not generate images inside the app. In the prompt section choose:

1. **Portrait:** square 1024 × 1024, recognizable appearance and up to three visual temperament cues.
2. **Expressions:** square sheet with four views of the **same** character, each showing a distinct emotion.
3. **In action:** a square narrative scene derived from the selected scenario, stakes and character conflict.

Each visual theme and image mode has its **own saved image slot**. For example, `original` portrait and `original__expressions` are distinct, so adding a sheet does not overwrite the portrait. The gallery can be filtered by image mode.

The prompt contains compact context for **all** polarities, but emphasizes only the most visually relevant axes. Adjusting any polarity changes the generated prompt unless you manually edited the prompt box; use **Regenerate** to rebuild it.
