# Characters and collections

## Character fields

In **Studio**, choose **New character** or open an existing entry. Enter the name, collection, archetype/role, interests and visual signature. Other sections cover motivations, insecurities, recurring emotions and typical reactions. Emotions are changing experiences, not permanent identities.

## Edit, duplicate and delete

- **Save** stores the current changes in the browser.
- **Duplicate** copies the character's data but does not duplicate portraits.
- **Delete** removes a character and its stored images. Export a backup first if needed.
- **TXT sheet** downloads a readable, re-importable record.

## Collections

The **Collection** field is a free-text grouping label, such as `kOA`. Use the sidebar **Displayed collection** filter to show a collection, show all collections, or show ungrouped characters. This filter also affects gallery visibility and batch prompt exports; it does not alter personality.

## King Klown

The included `fiches/king-klown.txt` describes **King Klown** in collection **kOA** as a benevolent trickster. His character combines playful wisdom, unpredictability, collective responsibility and a cosmic teal/gold/black visual identity. Import his TXT sheet through **Import** if needed.

A character can have a different image in each theme without changing their psychological profile.
