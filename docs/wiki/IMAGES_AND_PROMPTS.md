# Images and prompts

## Build a square portrait

1. Select a character and a shared **visual theme**: Original, Aliens, Women, Mythology, Hockey or Custom.
2. Choose the illustration style, such as Storybook, 3D video game, Comic book or Photographic.
3. Review **ChatGPT / DALL·E prompt**. It requests a **square 1024 × 1024** image and describes posture, gaze, expression and recognizable details.
4. Click **Copy prompt** and generate the image **outside Karacter**.
5. Save the image and drop it into **Character portrait**, or use the upload control.

## One character, multiple worlds

The personality axes remain the same when the theme changes. Karacter stores a **separate image per character per theme** so a character can appear as an alien, athlete or mythological creature without losing their underlying identity.

## Image behavior

Karacter accepts common image types (PNG, JPEG, WEBP, GIF and AVIF), with an individual upload limit of **30 MB**. It converts the center crop to a **1024 × 1024 PNG** for browser storage. Downloaded copies receive normalized names; the original file on your computer is not renamed.

## Batch prompts

Use **Gallery** or **Archetypes** to export **TXT prompts** for the currently displayed collection. The prompt is primarily in English regardless of the interface language. User-authored character descriptions are preserved in the language you entered.

**Important:** Karacter does not call DALL·E directly or automatically save image files to `portraits/`.
