# Images, thèmes et prompts

## Un thème visuel, une même personnalité

La bande supérieure permet de choisir un univers commun : **Original, Aliens, Femmes, Mythologie, Hockey** ou **Personnalisé**. Tu peux aussi choisir un style d’illustration. Ces réglages changent la description visuelle du prompt, **pas les polarités de la fiche**.

## Créer un portrait carré

1. Choisis le personnage et le thème.
2. Modifie, au besoin, sa **signature visuelle** et ses **polarités**.
3. Dans **Prompt ChatGPT / DALL·E**, clique sur **Copier le prompt**.
4. Colle le prompt dans ChatGPT et demande la création de l’image.
5. Enregistre l’image générée sur ton ordinateur.
6. Glisse le fichier dans la zone **Son portrait**, ou clique sur **Ajouter**.

Karacter prépare des instructions pour **un portrait carré 1:1, 1024 × 1024**. Il ne déclenche pas lui-même la génération d’image.

## Effet des polarités sur le prompt

Les tendances modifient les indications concernant le regard, les expressions du visage, la posture, la gestuelle ou les accessoires. Le personnage garde la même personnalité lorsqu’il change de thème.

Si tu réécris le prompt manuellement, utilise **Régénérer** pour revenir à une version cohérente avec les valeurs actuelles; la régénération remplace le texte personnalisé.

## Déposer un portrait

Formats acceptés : **PNG, JPEG, WEBP, GIF et AVIF**, dans la limite de **30 Mo** par fichier. L’application transforme l’image en **PNG carré 1024 × 1024** en recadrant au centre si elle n’est pas carrée. Vérifie donc que le personnage est bien centré avant de déposer l’image.

Un personnage peut garder **un portrait différent par thème**. Le fichier original sur ton disque n’est pas renommé. Avec le bouton de téléchargement du portrait, Karacter fournit une copie nommée par exemple `karacter_king-klown_alien.png`.

## Générer les prompts d’un groupe

Dans la **Galerie**, filtre éventuellement une **Collection affichée**, puis clique sur **Prompts TXT** pour télécharger les instructions des personnages visibles dans le thème actif. Tu pourras générer leurs portraits un à un dans ChatGPT.

## Conservation des images

Les portraits ajoutés à Karacter sont gardés dans le stockage interne du navigateur. Pour les conserver en même temps que leurs fiches, utilise **Sauvegarde ZIP** ou **JSON**; une simple fiche TXT n’inclut pas l’image.
