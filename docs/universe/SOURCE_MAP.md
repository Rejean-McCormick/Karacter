# Source map and scope

The `data/kristal-source-evidence.json` file contains selective, provenance-preserving extracts of the supplied package. This is a convenience index, **not** a replacement for the source repository or its canonical logical artifacts.

Source hierarchy: current creator clarification > governing decisions > canon > current canonical source > other source branches > media catalog > interpretation. A named counterpart in an event does not automatically establish their interior thoughts, appearance, ethnicity, occupation or a permanent relationship. Those features are marked creative.

`Aïda Mansour` and `Aïda Éloïse` remain distinct. The public persona, Colin Row and Ninja are modes under a shared creator-declared identity continuity. The Hello World metafictional author is distinct from the real-world creator.

The original Kristal zip also contains 24 works, 77 media manifestations and conceptual objects; they are not imported as characters. Media uploads are not treated as story events.
